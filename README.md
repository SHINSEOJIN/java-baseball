# 숫자 야구 게임 (Baseball Game)

## 프로젝트 소개
- 1~9까지 서로 다른 수로 이루어진 3자리 숫자를 맞추는 게임입니다.
- 입력값에 따라 스트라이크, 볼, 미스를 판정합니다.
- 3스트라이크를 달성하면 승리하며, 이후 재시작 또는 종료를 선택할 수 있습니다.

## 구현할 기능 목록
- 게임 시작 : "숫자 야구 게임을 시작합니다." 문구 출력
- 컴퓨터 숫자 생성 : 1~9 사이의 서로 다른 3개의 숫자를 랜덤으로 뽑는다
- 사용자 입력 : 사용자로부터 3자리 수를 입력받는다
- 입력값 검증 : 3자리 수인지, 중복이 없는지, 0이 없는지 검증
- 게임 진행 : 사용자의 입력과 컴퓨터의 숫자를 비교하여 스트라이크/볼/미스 개수 계산
- 결과 출력 : 스트라이크, 볼, 미스 출력
- 게임 종료 : 3스트라이크 달성 시 종료
- 재시작/종료 : 게임 종료 후 1 입력시 재시작, 2 입력시 종료

## 프로그램 실행 방법
- `Application` 클래스의 `main()` 메서드로 실행합니다.
