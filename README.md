# 숫자 야구 게임 (Baseball Game)

## 프로젝트 소개

- 1~9까지 서로 다른 수로 이루어진 3자리 숫자를 맞추는 게임입니다.
- 입력값에 따라 스트라이크, 볼, 미스를 판정합니다.
- 3스트라이크를 달성하면 승리하며, 이후 재시작 또는 종료를 선택할 수 있습니다.

## 구현할 기능 목록

- 프로그램 시작 문구 출력
- 컴퓨터가 랜덤한 3자리 숫자 생성
- 사용자로부터 3자리 숫자 입력받기
- 입력값 검증 (1~9, 서로 다른 수)
- 입력값과 컴퓨터 숫자 비교하여 결과 출력
    - 스트라이크, 볼, 미스 판정
- 3스트라이크 시 게임 종료 안내
- 게임 재시작/종료 선택 입력 및 처리
- 예외 발생 시 IllegalArgumentException 처리

## 프로그램 실행 방법

- `Application` 클래스의 `main()` 메서드로 실행합니다.

## 코딩 컨벤션

- Java Coding Conventions 준수
- 함수는 한 가지 기능만 수행하도록 작성
- 이름을 통해 역할을 알 수 있도록 명명 (자료형 명시 X)
