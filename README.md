# 숫자 야구 게임 (Baseball Game)

## 프로젝트 소개
- 1부터 9까지 서로 다른 수로 이루어진 3자리 숫자를 맞추는 게임입니다.
- 입력값에 따라 스트라이크, 볼, 미스를 판정합니다.
- 3스트라이크를 달성하면 승리하며, 이후 재시작 또는 종료를 선택할 수 있습니다.

## 구현할 기능 목록

### 게임 시작
- 프로그램 실행 시 "숫자 야구 게임을 시작합니다." 문구를 출력한다.

### 컴퓨터 숫자 생성
- 1부터 9까지 서로 다른 3개의 숫자를 랜덤으로 생성한다.

### 사용자 입력
- 사용자로부터 3자리 수를 입력받는다.
- 입력값이 정확히 3자리인지 검증한다.
- 입력값이 중복되지 않은 숫자인지 검증한다.
- 0이 포함되거나 중복된 입력일 경우 IllegalArgumentException을 발생시킨다.

### 게임 진행
- 사용자의 입력과 컴퓨터 숫자를 비교해 스트라이크, 볼, 미스를 계산한다.
- 결과를 "n볼 n스트라이크" 형식으로 출력한다.
- 일치하는 숫자가 하나도 없으면 "미스"를 출력한다.

### 게임 종료 조건
- 3스트라이크를 달성하면 "3개의 숫자를 모두 맞히셨습니다!" 문구를 출력하고 게임을 종료한다.

### 재시작/종료
- 게임 종료 후 사용자에게 재시작(1) 또는 종료(2)를 입력받는다.
- 1을 입력하면 새로운 게임을 시작한다.
- 2를 입력하면 프로그램을 종료한다.

## 프로그램 실행 방법
- `Application` 클래스의 `main()` 메서드를 실행하여 프로그램을 시작합니다.
